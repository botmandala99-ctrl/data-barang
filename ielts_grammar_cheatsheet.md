# 🔴 PART 1: PAST TENSE

## Aturan Emas #1
> **Jangan pake WAS/WERE kalo lo mau bilang KEJADIAN!**

| ❌ Salah | ✅ Benar |
|---|---|
| I **was go** to pharmacy | I **went** to pharmacy |
| Package **was arrive** | Package **arrived** |
| She **was call** me | She **called** me |
| I **was want** to be pilot | I **wanted** to be pilot |

**Gampang inget:** Kalo lo mau bilang ADA KEJADIAN → pake V2 langsung. WAS/WERE cuma buat "adalah/sedang".

## Kapan pake WAS/WERE?
> WAS/WERE = **kondisi / sifat**, bukan aksi!
- I **was** tired ✅ (kondisi)
- They **were** happy ✅ (sifat)
- She **was** a teacher ✅ (profesi)
- The weather **was** cold ✅ (keadaan)

## Past Perfect — Kalo ada 2 kejadian
> Kejadian **lebih dulu** → **had + V3**
> Kejadian **belakangan** → **V2**

Contoh:
- I **had eaten** (lebih dulu) before I **went** (belakangan) to work
- She **had already left** (lebih dulu) when I **arrived** (belakangan)
- I **had not seen** (lebih dulu) that movie before you **told** (belakangan) me

# 🔵 PART 2: SUBJECT-VERB AGREEMENT

## Aturan Emas #2
> **Kata-kata ini = SINGULAR, meskipun artinya banyak!**

| Kata | Arti | Verb |
|---|---|---|
| **Everyone** | Setiap *satu* orang | -s / is / has |
| **Every** + noun | Masing-masing | -s / is / has |
| **Each** + noun | Masing-masing | -s / is / has |
| **The news** | Berita (1 unit) | -s / is |
| **Mathematics** | Ilmu matematika | -s / is |
| **Physics** | Ilmu fisika | -s / is |
| **Economics** | Ilmu ekonomi | -s / is |
| **The price** | Harganya (1 harga) | -s / is |
| **Nobody** | Tidak ada *satu pun* | -s / is |

## Kartu Ingatan Cepat:

✅ Everyone **has** (bukan have)
✅ The news **is** (bukan are)
✅ Mathematics **is** (bukan are)
✅ The price **is** (bukan are)
✅ Each student **needs** (bukan need)
✅ Everybody **knows** (bukan know)

## Aturan NEITHER / EITHER
> Verb ikut **kata yang PALING DEKAT**

```
Neither the manager NOR the employees → were (employees = jamak)
Neither the employees NOR the manager → was (manager = tunggal)
```

# 🟢 PART 3: "THAT'S" vs "THERE ARE"

## Kesalahan paling umum lo!

| ❌ Salah | ✅ Benar |
|---|---|
| **That's** so many people | **There are** many people |
| **That's** so many women | **There are** many women |
| **That's** a lot of problems | **There are** a lot of problems |

**Gampang inget:**
- **THAT'S** = That is = "Itu adalah" (hanya 1 benda)
- **THERE ARE** = "Ada" (banyak benda)

# 🎯 RINGKASAN 5 MENIT SEBELUM TES

```
1. Past tense = V2 langsung. JANGAN pake was/were!
2. Everyone/Each/Every = singular → verb +s
3. News/Mathematics/Physics = singular
4. "That's" = itu adalah. "There are" = ada banyak.
5. 2 kejadian masa lalu → yang lebih dulu pake had + V3
6. Neither/Either → verb ikut kata terdekat
```
